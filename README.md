## What it is
`videolore` is a Rust project at its very beginning. Its requirements have not been defined yet: the purpose, users and features will be summarised here once the Product Manager writes `docs/business.md`.

## Installation
Requires Rust 1.88 or newer.
```sh
git clone git@github.com:andrealorenzani/videolore.git
cd videolore
cargo build --release
```

## Usage
```sh
cargo run
```
For now it prints a placeholder message.

## How it is built
The project is developed with an agentic workflow (Product Manager, Architect, Principal Engineer, Documenter) driven by `/add-feature`, `/change-workflow` and `/clone-workflow`. See [docs/workflow.md](docs/workflow.md).
