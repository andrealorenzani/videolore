# Support

## Questions and bugs

Ask questions and report bugs with GitHub issues:

https://github.com/andrealorenzani/videolore/issues/new/choose

When you report a bug, include:

- the videolore version (shown in the README and in the release you use);
- your operating system and its version;
- the steps that reproduce the problem;
- what you expected and what happened instead;
- the log or a screenshot, if you have one.

## Documentation

The [README](README.md) explains installation, usage and the known limitations.

## Security problems

Do not report security problems in a public issue. See [SECURITY.md](SECURITY.md).

## Response time

No response time is promised. The maintainer answers when time allows.
