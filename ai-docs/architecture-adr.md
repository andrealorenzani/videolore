## Platform, language, engine, concurrency
- ADR-001 (0.1.5) GUI eframe/egui 0.37. Alt iced, slint, gtk4-rs, tauri. Why: pure Rust, one binary, permissive licences. MSRV reasoning superseded by 012.
- ADR-002 (0.1) media engine ffmpeg/ffprobe as CLI subprocesses. Alt ffmpeg-next/sys (link pain, ABI churn), gstreamer-rs, pure-Rust decoders. Rules kept: no shell; `file:` prefix; `-protocol_whitelist file,pipe`; `-nostdin -hide_banner`; `-y` only on our temp output. "Not bundled" and "ffmpeg ≥ 4.4" superseded by 013; user override kept.
- ADR-003 preview audio cpal, null-sink fallback. Clock part superseded by 016.
- ADR-004 concurrency: std::thread, mpsc, Mutex/Condvar; no tokio. Cancel = AtomicBool and kill. Process cap: 015.
- ADR-005 support crates serde, serde_json, thiserror, directories, rfd, tempfile (MIT/Apache).
- ADR-012 toolchain: latest stable; rust-version = current stable (1.100); fix new lints; never pin old toolchains or crates. CI latest plus MSRV job.

## Export and media pipeline
- ADR-006 export tiers. T1 stream copy only if same source format, compatible output, no effects (fades, music, subtitle lines, video volume ≠ 100 % or muted) and keyframe cuts. Else T2 one re-encode. Temp in destination folder then rename; never overwrite a source. Input layout: 017.
- ADR-007 encoders: software first; `-encoders` probe at start-up; unavailable formats disabled. Hardware is an opt-in attempt for H.264/HEVC (037).
- ADR-008 fades min(0.5 s, clip/2), video and audio aligned.
- ADR-010 music via amix, volume, afade in T2; no crate. Detail in 019.
- ADR-015 (0.2.0, 0.3.0) process scheduler (REQ-033). `jobs::Scheduler` Mutex plus Condvar; cap set per effort level (`set_cap`, 3..=6, 029). Priority Preview=0, Export=1, Probe=2, Background=3. `acquire(prio, slots, cancel, preempt)`; grant when in_use + slots ≤ cap and no earlier waiter. Preemption: an unsatisfiable Preview or Export waiter preempts the lowest running proxy (kill, requeue, restart from 0); probes and STT extraction are not preempted; export never. `Scheduler::runner(prio)` returns `LimitedRunner`; `spawn` keeps the permit until wait, kill or drop; `spawn_group` takes two slots atomically. Slots: playback 2 (video and audio together; a single muxed process rejected), still 1, export 1, probe 1, proxy 1 (preemptible), STT extraction 1 (Background). Export plus playback = 3. Still frames: latest-only mailbox. New, Open and close cancel the project's jobs. Start-up ffmpeg check on a background thread with "checking ffmpeg…". STT inference is not in the cap.
- ADR-016 (0.2.0) preview, REQ-034/035. Supersedes 003 audio clock. `FrameKey` (pure) at t: segment media, effective path (proxy or original), source frame index (fps-snapped), fade parameters, output geometry, visible subtitle cues. Render only if the key changed, after 80 ms debounce (injected clock). Edits after the playhead: 0 renders; 10-edit burst: at most 1. Still graph: single segment at the playhead. Clock: wall clock master; `audio_correction(device_pos, wall_pos)` → None, Drop(n), Pad(n) at 40 ms. Video never waits for audio. Music preview uses the export's `audio_graph`. Subtitles: same ASS and font, subtitles filter after scale, PlayRes = export geometry. Alt rejected: audio as master (the 0.1.3 freeze).
- ADR-017 (0.2.0) export inputs grouped in monotone runs (REQ-037; supersedes one input per clip). Consecutive segments from one source with `src_in(i+1) ≥ src_out(i)` share one input: `-ss run_start -t run_len+1s -i file:`; `split` for video and `asplit` for audio; per-segment trim. A new input only when time goes back. Graph via script file above 8 KiB. Music grouped the same way. Alt rejected: one input per clip (200 decoders); one input per source with split for reordered clips (unbounded queues). hvc1 (REQ-036): `-tag:v hvc1` for HEVC in mp4 or mov, copy and re-encode.
- ADR-018 (0.2.0) proxies (REQ-038/039). Rule `needs_proxy(w, h, machine)` = w·h > 1920·1080 or (w·h > 1280·720 and (cores < 8 or RAM < 8 GiB)); display size with rotation; audio-only never. Format libx264 veryfast crf 23, keyframe every fps/2, fit 960x540 even, 128k AAC, Matroska, `.partial` then rename; progress to the media item. Cache `ProjectDirs::cache_dir()/proxies/<key>.mkv`, key = first 32 hex of SHA-256(absolute path, size, mtime ns, PROXY_PARAMS_VERSION). Clear deletes only `^[0-9a-f]{32}\.mkv(\.partial)?$`. No automatic eviction. Export never uses proxies. 0.3.0: switch superseded by Preview quality (029). Memory caps: preview channel 8 x 640x360 RGBA; audio 1 s; stderr 64 KiB; stdout 16 MiB; STT chunk 120 s; keyframes line by line.
- ADR-019 (0.2.0) music mix (REQ-019/020/043). Bed = concat of anullsrc gaps and music segments (atrim, asetpts, aresample 48000, aformat fltp stereo), trimmed to the video length; a clip past the end fades out over 0.5 s. `[va]volume=gv`, `[mus]volume=gm`, `amix=inputs=2:duration=first:normalize=0`, `alimiter=limit=0.97`. Gain (p/100)^2 (50 % ≈ −12 dB); mute → 0. Music does not ripple with video edits. Lane under the video track; sliders record undo on drag stop.
- ADR-033 (0.3.0) private work folder and crash clean-up (REQ-059). `scratch::Work::new(kind)` → `<cache>/videolore/work/<rand>/` mode 0700, `lock` file (std `File::try_lock`, held for the job) and `targets` (partial paths outside the folder). Holds extracted audio, ASS, font copy, filter scripts; ffmpeg cwd = work folder. Export partial `.<name>.videolore-partial` (create_new, 0600, registered); success → 0644 and rename; failure or cancel → remove. Proxy `<key>.mkv.partial` and model `<file>.part` registered the same way. `cleanup_stale()` at start: a folder whose lock is free is stale; targets matching `^\..+\.videolore-partial$`, `^[0-9a-f]{32}\.mkv\.partial$` or a known model `.part`, regular and not a symlink, are deleted, then the folder. A held lock (another window) is left alone. Cache and data dirs 0700. Alt rejected: system temp (RAM-backed `/tmp`, shared); PID liveness (reuse); age-based deletion (races).
- ADR-035 (0.3.0) test speed (QG-03). Fixtures generated once per parameter set in `CARGO_TARGET_TMPDIR/fixtures/<sha256(params + ffmpeg version)>.mp4` (`.partial` then rename). Smaller media where size is irrelevant (320x180 except geometry tests; 160x90 at 10 fps for memory). Fixed sleeps replaced by channels. `[lib] doctest = false`; `[profile.dev] debug = "line-tables-only"`. Target: `cargo test` wall ≥ 30 % below the M0 baseline (median of 3); no test removed. Runner `cargo test` (nextest rejected: breaks the annotations script). CI check job: one instrumented run `cargo llvm-cov --locked --ignore-filename-regex 'src/main\.rs$' --fail-under-lines 85 --summary-only`. msrv job: `cargo build --locked --all-targets` only. OPEN (needs /change-workflow): the local suite runs tests twice (cargo test plus coverage script).

## Speech and subtitles
- ADR-009 (0.1) STT whisper.cpp via whisper-rs; model ggml tiny-q5_1 multilingual, downloaded after consent (not bundled). Superseded in parts by 022 (stt on by default) and 030 (three models). Alt: cloud APIs (privacy), Vosk (quality), candle-whisper (performance, maturity).
- ADR-020 (0.2.0) subtitle model and burn-in (REQ-016/017/018). Lines stored in source time; the timeline shows, per video clip, the lines of its media intersecting `[src_in, src_out)` mapped to `clip_start + (s − src_in)`; words outside hidden. Cut removes, copy duplicates, split keeps. Re-time through the shown clip, clamped. Add at playhead: the clip under it, 2 s default. Text edit clears words; highlight spreads evenly by word count. Burn-in: `ass::write(shown, preset, geometry)` → `subs.ass` plus `NotoSans-Bold.ttf` in `fonts/` in a private folder used as cwd; filter `subtitles=f=subs.ass:fontsdir=fonts`. Relative names avoid path escaping. Size = min(0.055·H, 0.09·W); margins scale. Presets: Classic (white, black outline, bottom); Box (white on semi-opaque box, BorderStyle 3, lower third); Word highlight (bold white, current word yellow by `{\kNN}` SecondaryColour → PrimaryColour, centre-low, ≤ ~4 words per chunk). Escape `{` → `(`, `}` → `)`, `\` → U+FF3C; only our code emits `\N` and `\k`; text cap 1000 characters.
- ADR-021 (0.2.0) STT pipeline (REQ-014/015/044). whisper-rs 0.16.0 (Unlicense); whisper-rs-sys 0.15.0 (rust-version 1.88); build needs cmake, C++ compiler, libclang. whisper.cpp MIT, CPU only. Model `ggml-tiny-q5_1.bin` from `huggingface.co/ggerganov/whisper.cpp/resolve/5359861c739e955e79d9a303bcbc70fb988958b1/`, 32152673 bytes, sha256 818710568da3ca15689e31a743197b520007872ff9576237bda97bd1b469c3d7 (checked 2026-11-14). Stored in `ProjectDirs::data_dir()/models/`; `.part`, exact size and sha, then rename. Consent dialog before any network call. Local file option (same size and sha). ureq 3.5.2 (rustls, `default-features = false`) → rustls 0.23, ring 0.17 (Apache-2.0 AND ISC), webpki-roots 1.0 (CDLA-Permissive-2.0). HTTPS only; redirects HTTPS only; connect and read timeouts; `HTTPS_PROXY`. Only the downloader uses the network. Traits `Transcriber` (`transcribe(pcm, offset, lang, cancel)`) and `ModelFetcher`; fakes in tests; integration test gated by `VIDEOLORE_STT_MODEL` (CI: model cached by sha, a spoken "hello world, this is videolore", asserts "hello" and increasing word times). Word timestamps: token timestamps on, split on word, max length 1; lines at pauses > 0.6 s or the preset limit. Language auto on the first chunk, stored in the project, override re-runs. One STT job at a time; extraction 1 Background slot; 120 s chunks; cancel by the abort callback; progress chunk/total. Scope: each timeline source in full; video audio only. Alt rejected: cloud, Vosk, candle, reqwest (tokio) vs ureq, native-tls (OpenSSL) vs rustls.
- ADR-022 (0.2.0) cargo features: default `["audio", "stt"]`; `stt = ["dep:whisper-rs", "dep:ureq"]`. Supersedes 009 (off by default). Source builds need cmake, C++, libclang; `--no-default-features` gives "Generate subtitles: not available in this build". CI runs default, `--no-default-features` and `--all-features`. - ADR-053 (1.2.0) embedded text subtitle tracks: ffprobe detection plus ffmpeg extraction to SRT (REQ-086/087). `-show_streams` JSON already exists (no new process). Codec allow list subrip, srt, ass, ssa, mov_text, webvtt, text; picture codecs ignored. ≤ 16 tracks; ordinal `-map 0:s:N` counted by us (u8). Language `[A-Za-z0-9-]{1,16}` else none; title sanitised, ≤ 64 characters; a bad entry never rejects the media. Media imported before 1.2.0: background re-probe on open (patches current and saved doc; no dirty mark). Extraction `-hide_banner -nostdin -loglevel error -y -protocol_whitelist file,pipe -i file:<src> -map 0:s:<N> -c:s srt -f srt file:<work>/track.srt` (Background, cancellable). Read with `read_limited` (16 MiB) then `srt::parse`. Assumption: cue times relative to file start (test with `-output_ts_offset`). - ADR-054 (1.2.0) in-house `srt.rs` parse and write; SRT export (REQ-088). `write`: sort by (start, line id), number from 1, `HH:MM:SS,mmm --> …` (ms floored; end ≥ start + 1 ms), LF, UTF-8 no BOM, empty-text lines skipped. `parse`: tolerant (`,` or `.`, CRLF, BOM, missing index, junk skipped); caps 100,000 cues, MAX_TEXT; checked arithmetic; hours ≤ 99,999; end > start or dropped; total function. `strip_tags` removes `{…}` and `</?[A-Za-z][^>]*>`, `\N`, `\n`, `\h` → space, then `clean_text`. Export: rfd save `<project name>.srt`; `write_atomic`; UI thread (10k lines < 100 ms); greyed "No subtitles on the timeline". Alt: srtparse, subparse, srtlib crates.
- ADR-055 (1.2.0) subtitle creation per range with modes Recognise, Align, Spread; all or nothing (REQ-085/087/095, 044, 052, 054, 015; Andrea S2 = A, S3 = B). Ranges: clip → (media, src_in, src_out); whole video → each source in full. Extraction `-ss from -t len` before `-i`; offset = from + chunk offset. Modes: Recognise (path as today); Align {track, language} (track text plus recognised words aligned, 056); Spread {track} (track text with evenly spread words, no recognition). Dialog `Modal::SubtitleSource` when a source has a usable track, asked every time. Without speech support or build feature: wording "(this computer cannot match words to the speech; they will be spread evenly)", Spread, no download. Consent with extra "Use without matching words". Fallbacks: cue < 50 % matched or no speech → even spread and the status count; CPU or build cannot recognise → Spread; download refused → Spread; recognition fails → that range Spread plus message. Align never fails the job. Result: one undo "Create subtitles"; `replace_range(media, from, to, lines, language)` removes overlapping lines of that media, adds new ones clamped, `edited = false`; whole video → `replace_all`. Language from the track (ISO 639-2 → 639-1 static table; und → detect) unless the user overrode (REQ-015). REQ-044 asks only for hand-edited lines overlapping the ranges. One job at a time (M18). Cancel: nothing, no undo. Progress "Matching subtitles to the speech" when any Align range. Alt rejected: Spread only (accurate highlight wanted); re-timing cue start and end (out of scope); per-range undo steps (partial results on cancel).
- ADR-056 (1.2.0) word alignment: per-cue Needleman-Wunsch, in-house, deterministic (REQ-095). Tokens: `split_whitespace` (spelling kept); normalised = Unicode lowercase, alphanumerics only; empty normalised never matched. Recognised words normalised the same way. Per cue in time order with a monotonic cursor; candidates = recognised words starting in `[cue.start − 1.0 s, cue.end + 1.0 s]` and index ≥ cursor. Scores: exact +2, fuzzy +1 when `lev(a, b) ≤ max(1, floor(len/4))` and both ≥ 3 characters (short words exact only), substitution −1, gap −1; traceback prefers the diagonal. Cue matched iff matchable > 0 and matched/matchable ≥ 0.5; else even spread (`ShownLine::word_at`, `ass::words_of`, D13). Matched start = recognised start clamped to `[cue.start, cue.end)`, non-decreasing; unmatched runs spread between anchors; end = min(own end, next start), ≥ start + 10 ms, clamped; final pass guarantees `validate_subtitles`. Line start and end = the cue (never re-timed). Performance: 10k cues < 50 ms. Gated test: committed fixture `tests/fixtures/align/speech.mkv` (~20 s Opus with an SRT, one misspelling, < 100 KB) and `reference.json` word starts; `make.sh` (dev only, espeak-ng). Fast model: ≥ 90 % words matched within 0.3 s. Alt rejected: global DP over the track (memory, drift); strsim crate (~20 lines in-house); whisper DTW (needs alignment heads); forced aligners (new model download).
- ADR-057 (1.2.0) per-line on-screen position via ASS `\pos`; preview drag; selection as UI state (REQ-089..092). `Pos{x, y: u16}` = box centre in 1/10000 of the frame (survives output format changes). None = preset place (1.1 output identical). ASS `{\an5\pos(X,Y)}` from our code with validated u16 only; escape unchanged. Preview equals export (same `ass::document`, PlayRes = export geometry). Hit test and clamp by `placement::boxes` measuring with egui layout and the bundled font (`ass::FONT`, `FontFamily::Name("subtitle")`, `ass::font_size(W, H)`, wrap `W − 2·margin_lr + box_padding`); measure function injected (fake in tests); centre clamped to `[w/2, W − w/2] × [h/2, H − h/2]`. Drag: transient `drag_pos` (not history or project; part of FrameKey → latest-only still); ghost painted at once; release → `SetLinePositions` (one undo). Group: every selected line gets the dragged line's final position; only the dragged box is clamped. Selection: `BTreeSet<LineId>` in AppState, not in history or project; pruned after edit, undo, redo. Ctrl/Cmd+click toggles on markers and in the popup list; plain click replaces and opens; Shift+drag on the tracks rect (registered after clips, only when Shift at press) selects lines whose start is in range; +Ctrl/Cmd adds; seek to the first selected; Esc topmost popup else clear. Reset position: popup, Effects menu, marker menu; on a selection resets all. Alt rejected: MarginL/R/V (no free 2D placement); egui overlay preview (preview ≠ export); ab_glyph or fontdue (new crate); selection in history (undo jumps selection). Known limits: egui vs libass width differs by pixels at edge clamp (ASS authoritative); text edit after a drag may cross the edge; overlapping positioned lines overlap.
