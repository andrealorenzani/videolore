## Role notes useful for changes (short)
- `timeline`: clips, cuts, fades (`fade_in`/`fade_out` flags since 1.6.1), volume, clean audio, speed (`Clip::len`, `src_len`, `to_timeline`, `to_src`), `clip_aspects`, `clip_overlaps` (2.3.0), `clip_order`; pure.
- `project`: formats 1..14; writer 14; `v9` (8 to 9) and `v13` (13 to 14, 2.3.0; picture item becomes overlap) conversions in memory; `Project.converted: Option<Conversion>`; `project/order.rs` (repair, put_on_top); `read_limited`/`write_atomic` via `base::io`.
- `render`: `export_args(plan, paths, version, threads, hw)`; None = byte-identical 0.3.0 argv (golden tests); `graph.rs` (`build_graph`, `lut_chain`, `overlay_chain`, `write_command_files`); `plan.rs` (`picture_overlays`, `PicOverlay{look}`); `overlay.rs` (2.1.0 `OverlayStep::{Lut, Ass, Pic}`); `steps.rs` (2.2.0 step builder); `segments.rs` (`anchored_line_items`).
- `lut`: `parse` (streamed, `MAX_3D` 256, `MAX_BYTES` 512 MiB, `MAX_LINE` 256, `MAX_WHOLE` 64 MiB), `store` (cache 192 MB, `Load`, `Prep`, `peek`, `copy_name`/`write_copy`, `is_prepared`), `mod` (API).
- `effect_order`, `order_chain`: rows and groups (see human effects doc); `app/applied.rs` rows cache with revision; `ui/applied_effects.rs`; `ui/layout.rs` (`applied_width`, `drag_applied`).
- `overlap` (pure) and `app/overlap.rs`; `picture` (`read`, `read_overlay`, `overlay_usable`, `MAX_PICTURE_PIXELS` 16,000,000); `ui/overlap_lane.rs`, `ui/overlap_box.rs`, `Modal::RemoveOverlaps`, `app::overlap::REMOVAL_ASK`.
- `text`: `timing`, `layout` (`TextItem::cap()`, `max_size`), `events`; `measure` (skrifa, harfrust; `place_words`), `word_styles`, `ass` (`word_centres`, `highlight_chunks`, `style`, `document_styled`).
- `camera`: `Camera` (centi-degrees), `Pov` (source time, roll, ease), `CameraPaths` (source map + per-clip `clips`), `command_lines`, `command_lines_speed`, `start_camera`, projection; `spherical`: MP4/MOV writer and MKV/WebM in-place marker.
- `export`: `ExportJob` with `hw: Option<HwOffer>`, watchdog 30 s, outcheck, sw redo; `prepare_spatial`; `export::choice` (name/extension/clash rules).
- `hwenc`: `Codec`, `Vendor`, `Candidate`, `candidates`, `render_nodes`, `encode_args`, `probe` with `ProbeLimits` (1 s, 4 s, 10 s), `HwStatus` (+ `inconclusive()`), `Reason`; libva guard by byte scan (never dlopen).
- `outcheck`: ffprobe JSON, decode progress, psnr log; `CheckFailure{Decode, FrameCount, Metadata, Picture}`; CQ size rule (> 1.5x → fail, not remembered).
- `ffmpeg`: locate, probes, `Runner` (spawn/run; stdout cap 16 MiB; stderr ring 64 KiB); only module that spawns ffmpeg; `SystemRunner` in programs, fakes in tests.
- `jobs`: Scheduler (cap set by level, MAX_CAP 6), Permit, LimitedRunner, preemption; every ffmpeg/ffprobe spawn goes through it. STT whisper is outside the cap.
- `preview`: wall-clock master, audio drift correction, latest-only still mailbox with 80 ms debounce, `FrameKey` (incl. order, overlaps), `prepare_spatial` (`Preview.prepass`), `input_codecs`, `hwdec` integration.
- `proxy`: rule, key, cache dir, background generation, `needs_proxy_360` (w > 4096 → 4096x2048).
- `stt`: `Transcriber` and `ModelFetcher` traits with fakes; `WhisperTranscriber` and `UreqFetcher` under feature `stt`; `Mode{Recognise, Align, Spread}`; ranges; `speech_regions` use in `align::retime_with`; `FROZEN = None` (REQ-177).
- `align` (NW, ADR-056, 2.0.3 sound correction) and `srt` (ADR-054) are pure.
- `machine`: `Machine` (cores, RAM, OS, `CpuFeatures`), `detect`, `speech_supported`, `fingerprint`; tests inject Machine.
- `settings`: v2 with optional fields (export, hardware_off, layout, recent, show boxes, applied_share, splash option); `startup(bytes, &machine)` pure; `recommend`, `budget`, `availability`.
- `scratch`: `<cache>/work/<rand>/` 0700, lock, targets registry, `cleanup_stale()` at start; `default_root`.
- `desktop`: Linux desktop integration and removal; macOS open-document handler and menu call (the only unsafe sites with `stt.rs` callback).
- `splash`: `Program{image, summary, text_rect}` with `EDITOR`, `PLAYER`; `should_show`; `include_bytes!`/`include_str!` from `assets/splash/`; decode caps.
- `notices`: static table plus `rust-crates.txt` / `rust-crates-player.txt` (include_str!).
- `ui`: `frame_ui` order: tick; dropped files; keymap (consumes matched events); top menubar + toolbar; bottom statusbar; central content split by `ui/layout` (`Fractions`, `Mins`, `GAP` 6 px, `Splitter`); popups as `egui::Window`; modals; dispatch; `ctx.options_mut(zoom_with_keyboard=false)` (ADR-046). `actions.rs` (`ActionId`, `ACTIONS`), `status.rs` (`background_jobs()`), `markers.rs` (pure), `ruler.rs` (ADR-058), `placement.rs` (`line_box`, `off_view_arrow`), `frame_handles.rs` (`Hit` incl. `Edge`), `splash_window.rs` (both programs), `splash_ui.rs` (editor adapter), `icons.rs`, `strings.rs`, `theme.rs`, `keymap.rs`, `place.rs`, `view_menu.rs`.
- `app`: `AppState::dispatch` → `DISPATCH_AREAS` (project, subtitles, settings, interface, playback, view, effects, objects); `tick()` drains channels once per frame; `HwState{probe, last_method}` (session only); generation counters drop stale results; `edit()` with overlap removal check; `subs_create`, `texts`, `frame`, `lut`, `overlap`, `applied`, `camera` live view, `recovery`, `autosave`.
- `player`: `PlayerState` (Command, tick), `ui::PlayerApp`, `subs`, `fullscreen`, `settings`, `playlist`, `siblings`; no save, export or edit command.

## Data flows (ai view, short)
- Edit: UI event → `AppState::dispatch` → mutate Edit → history (named) → dirty recompute → `FrameKey` at playhead → if changed, latest-only still request after 80 ms (injected clock).
- Import: `Command::Import` → placeholder Analysing → probe pool → mpsc → `tick()` Ready/Rejected → proxy rule may enqueue.
- Export: `render::plan_export(project, Source::Export)` (originals) → export thread, Export runner (one ffmpeg) → progress → atomic rename. Hardware (0.4.0, ADR-039): `hw = Some(offer)` only if Faster, probe Done, method not in `hardware_off`, codec H.264 or HEVC; hw run to `.<name>.hw.videolore-partial` (progress 0 to 0.85), watchdog, outcheck (0.85 to 1.0), rename; on failure kill (wait ≤ 5 s, then abandon), delete partial, software redo with 0.3.0 args (`SoftwareAfterProblem`); a failing redo is a plain failure, nothing remembered.
- Probe (ADR-038): triggers: start-up with saved Faster, switch to Faster, "Try video hardware again", "Use recommended settings", ffmpeg override change while Faster. Best quality → nothing runs.
- Subtitles (ADR-055): `ApplyEffect{Subtitles}` → job running? greyed → ranges → tracks unknown? probe, resume in tick → hand-edited overlap? REQ-044 confirm → track usable? `Modal::SubtitleSource` (Use/Recognise/Cancel) → model needed? consent modal, "Use without matching words" (→ Spread) → `stt::start` (one thread, 120 s chunks) → Done → one undo "Create subtitles". Cancel or failure: nothing, no undo.
- Subtitle track media re-check: project open → media without tracks → background ffprobe → patches current project AND saved doc (dirty unchanged).
- Preview box drag: press on box (topmost) → clamped centre → ghost + FrameKey → latest-only still → release → `SetLinePositions` (one undo).
- Selection: marker click (Ctrl/Cmd → toggle) → `SelectLine`; Shift(+Ctrl/Cmd) drag → `SelectRange{from, to, add}` → seek to first; Esc: topmost popup, else `ClearSelection`.
- Effects: row click → `OpenPopup`; double-click → `ApplyEffect{WholeVideo}`; drag → egui `DragAndDrop` payload `EffectKind` → timeline `dnd_hover`/`dnd_release` → `ApplyEffect{Clip}`.
- Settings: startup: `Machine::detect` → `scratch::cleanup_stale` → `load_file` (regular, ≤ 64 KiB + 1) → `startup()` pure → save if needed → `budget()` → `sched.set_cap` → preview mode. `SetEffort` → budget and cap (running jobs keep args); `SetPreviewQuality` → queue needed proxies; `SetSubtitleQuality` → save only, never regenerate. All saves atomic.
- Layout: splitter drag → `UiCache.layout_drag` (live, no save) → `SetLayout(Fractions)` on drag end → one atomic save; `ResetLayout`; opening a project never touches the layout.
- Actions: menu, toolbar, context menu, keymap → `ActionId::command(&app)` → `Command` → dispatch; keymap skipped while text input or modal; Esc: egui popup, else topmost own window, else most recent.
- Recent: successful open or save → `push_recent` (dedupe, front, max 10) → save; `OpenRecent` on a missing file removes it and reports.
- Drop: `DropFiles` → modal open → ignore + status; project → guarded open (REQ-028) + "N other files ignored"; media → import. Wayland: winit 0.30 emits no drop events (ADR-047).
- Double-click: Windows and Linux argv → `Command::OpenPath`; macOS open-document → mpsc → tick → `OpenPath`; both through the REQ-028 prompt; the player takes a video path and refuses `.vlproj`.
- SRT export: save dialog `<name>.srt` → `srt::write(subtitles.project(&timeline))` → atomic write (UI thread, like save).
- Camera: drag → `DragCamera` (live, window state); zoom → `ZoomCamera`; Set POV → `SetPov`; export → `camera::command_lines` per frame → `v360@cN`.
- Spatial (2.0.4): `export::prepare_spatial` after the work folder (four-channel decode through Runner → `spatial::prepare` rotates 480-sample blocks with the camera at source time → `spatial-<hash>.wav` .part → rename) → `Segment.spatial` → graph reads it in place of the clip sound; preview: `Preview::prepare_spatial` before audio, wall clock shifted by `Preview.prepass`.
- Picture subtitle (2.0.4): `MediaFormat.picture_tracks` → `Project.picture_sub` (runtime) → `Segment.picture_sub` → overlay before trim in the shared graph.
- Picture item (2.0.4): `Command::AddPicture` → `picture::read` (header) → text item with picture → `render::picture_overlays` → looped still + overlay before subtitles.
- Overlap (2.3.0): `AddOverlap` → clip under playhead → `picture::read_overlay` → overlap in clip; `AppState::edit` detects losses → `Modal::RemoveOverlaps` → `ConfirmRemoval` reruns with `removal_confirmed` (one undo).
- LUT (2.2.0 route D): choose → store preparation (Loading with percentage, Ready) → Work copy `lut-<hash16>.cube` → graph includes the row only when Ready; applied commands → revision → rows rebuilt once.
- Threads: UI (eframe) → frame_ui → dispatch/tick. Workers: ffmpeg check (mpsc), hardware check (mpsc), probe pool (MAX_CAP, mpsc), proxy pool (1 worker), export worker + stdout reader + reap, still thread (latest-only mailbox), playback (sync_channel FRAME_BUFFER; audio reader → AudioBuffer Arc → cpal `AudioSink`), speech (SttEvent), model install (ModelEvent), track reader, LUT load and prep (`Load`, `Prep`: percent, table), font scan (Arc Mutex list), autosave worker. Cancel = `Arc<AtomicBool>` per job; `Limited::cancellable` kills processes; a dropped job's channel makes late results go nowhere; processes always via `ffmpeg::Runner` with argument lists.
