Cancelled : sw redo into .<name>.videolore-partial w/ 0.3.0 args (progress back to 0 once, no message) -> Done SoftwareAfterProblem; redo fail -> Failed as 0.3.0, nothing remembered.

## Threads and channels (verified in code-architecture)
UI thread (eframe): frame_ui -> dispatch/tick. Workers: ffmpeg check thread (mpsc FfmpegInfo); hardware check thread (mpsc HwStatus); probe Pool (MAX_CAP workers, mpsc ProbeResult); proxy Pool (1 worker, ProxyEvent); export worker (ExportEvent) + stdout reader + reap threads; still thread (mailbox latest only, Frame); playback thread (sync_channel FRAME_BUFFER, audio reader -> AudioBuffer Arc -> cpal callback AudioSink); speech thread (SttEvent); model install thread (ModelEvent); track reader thread (mpsc); font scan thread (Arc Mutex list). Scheduler limits all ffmpeg/ffprobe processes; STT whisper outside cap.
Nothing slow runs on UI thread; cancellation = Arc<AtomicBool> per job + Limited::cancellable kills processes; a dropped job's channel makes late results go nowhere; processes always via ffmpeg::Runner with argument list, never a shell.
