# ai-notes: NFR targets (owner: architect; index in ai-docs/architecture.md)

Status tags: GATE (test fails the build), ESTIMATE, ASSUMPTION, MEASURED, NOT MET. Version of origin in brackets. The human version: docs/architecture-nfr.md.

## Processes, scheduling, threads
- GATE: ffmpeg/ffprobe never above the cap: 3 (Light, Balanced) or clamp(L/2, 3, 6) (Maximum; 3 if RAM < 7 GiB). Test: 20 imports + export + preview at L = 1, 8, 16, high-water ≤ cap, all complete. [0.2.0, ADR-029]
- Cap floor 3 (playback 2 + export 1). Track extraction and range extraction: one Background slot each, sequential (REQ-033). Whisper outside the cap. [1.2.0]
- Hardware probe: one Probe slot; 1 s first try + one 4 s retry per candidate; ≤ 10 s total; at most one automatic repeat when inconclusive (≤ ~20 s background). CI real probe bound = total + 1.5 s, two runs equal, finds no hardware. [0.4.0, 0.4.2]
- Hardware export: stall 30 s; post-kill wait ≤ 5 s then abandon; cancel < 1 s in every phase (poll ≤ 250 ms); one partial at a time; a killed process keeps its Export slot until it exits (ADR-039). [0.4.0]
- Export progress ≥ 2/s; cancel < 1 s; no partial outputs; atomic project and settings saves. [0.2.0]
- UI thread: no subprocess or blocking I/O except project save/load (≤ 16 MiB), settings (≤ 64 KiB), small desktop writes at start-up. Never wait on a lock held across worker I/O (try_lock or channels). [0.2.0, 0.3.0]

## Platforms, build, verification
- Platforms: Linux x86_64 (Ubuntu 24.04 and 26.04 LTS, current Fedora; glibc 2.39 max, `package.sh` fails above); macOS Apple Silicon; Windows x86_64. Intel Mac, ARM Windows and ARM Linux out of scope (REQ-040 unchanged).
