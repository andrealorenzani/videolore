## Verified facts used (checked 2026-11-26)
- Bundled ffmpeg 9.0.2 (packaging/ffmpeg.lock): BtbN scripts.d lists 45-pulseaudio.sh, 45-x11, 50-libmp3lame.sh, 50-x264.sh (per-variant enablement not read; the smoke test decides); Riedl macOS and BtbN win64-gpl-shared: gdigrab and avfoundation are built in (to be confirmed by the smoke test `-devices`). No WASAPI input in ffmpeg (FFmpeg ticket #9408 open). No PipeWire screen input (patches only).
- PCM in an MP4 is refused by the ffmpeg mp4 muxer (ticket #2346 and later); MOV, MKV and AVI accept PCM. Hence WAV goes into MKV (REFINE A).
- cpal 0.18.2 (Apache-2.0, latest 2026-08-16): WASAPI output device used as input = loopback (shared mode, no driver); macOS loopback since 0.17.0 on macOS > 14.6 (MSRV table: 14.6+ for loopback).
- display-info 0.5.10 (Apache-2.0): screen geometry on Linux (smithay-client-toolkit, xcb randr), macOS (CoreGraphics), Windows (GDI). Its rust-version is not stated.
- xcap 0.9.10 (Apache-2.0): Linux build depends on pipewire 0.10 and ashpd; Wayland capture is screenshot-oriented. Not used.
- scap 0.1.0-beta.1: pre-release, no audio. Not used. pinray 0.2.4: unstable minor API. Not used.

## Assumptions (not measured; PE or Andrea checks)
- A-3.1.2-1 the pinned builds contain gdigrab, avfoundation (built in), x11grab, pulse, libx264, aac, libmp3lame and pcm_s16le in MKV (smoke test at package time decides).
- A-3.1.2-2 `mp3` inside MP4 is accepted by the ffmpeg muxer (step 8).
- A-3.1.2-3 avfoundation screen index order equals the CoreGraphics display order used by display-info (manual check, item 38).
- A-3.1.2-4 gdigrab accepts negative offsets for screens left of the primary (manual check on Windows).
- A-3.1.2-5 `@DEFAULT_MONITOR@` and `@DEFAULT_SOURCE@` resolve through PulseAudio and PipeWire's pulse layer (step 8 with the null sink; real desktop manual).
- A-3.1.2-6 cpal 0.18.2 WASAPI loopback works in shared mode on the default output device without a driver; macOS loopback needs 14.6 or later and the system-audio permission.
- A-3.1.2-7 libx264 `veryfast` keeps 1080p30 in real time on a four-core x86_64 machine (not measured; measure before release).
- A-3.1.2-8 display-info 0.5.10 builds with the MSRV of the CI msrv job (checked by CI; if not, the crate is replaced).
- A-3.1.2-9 fragmented MP4 and Matroska files plays in the players used by the business checks (step 8 with ffprobe; manual in item 38).
- A-3.1.2-10 the Linux CI runner can install xvfb and pulseaudio (apt, default repositories) and start both.
- A-3.1.2-11 the `amix` of two inputs with different rates and channel counts converts inside ffmpeg (step 6 argv; real run in step 8).
- A-3.1.2-12 the player adds to the playlist without starting playback when the playlist had ended (chosen here, ADR-267).
- A-3.1.2-13 cpal's CoreAudio tap symbols (macOS 14.2 and later APIs) do not make the executable fail to launch on older macOS: they are weakly linked or only reached at run time (PE check in step 10; if not, see ADR-259 fallback).

## Test plan summary
Unit (pure, all three Os on Linux CI): plan argv, format and audio tables, container rule, default name, settings corpus, session decision (Wayland, X11, XWayland), macOS version decision, screen labels, device parsing, PCM conversion, silence padding, peer rule, state machine. Fake runner for process rules. Real ffmpeg on Linux CI (step 8, gated by `VIDEOLORE_REQUIRE_CAPTURE`): MP4 and MKV recordings, partial files playable after kill, preview rate. Player: playlist tests (step 1). Manual (business verification items 38 and 39): screen recorder on each system including an older Mac message; playlist from Open. Coverage: line coverage of the whole workspace (main.rs excluded) at least 85 %; `cfg`-gated adapters reported separately by the PE.

## Risks (for the record; details in architecture-risks.md)
- A/V sync between the ffmpeg video clock and the app's audio clock: wall-clock timestamps on both inputs; measure the start offset on Windows and macOS (manual).
- WASAPI and CoreAudio loopback send nothing while silent: silence padding keeps the track length right (unit test; manual check).
- Preview switch at Start (about 1 s pause, ADR-257).
- Installer size: three products with their own ffmpeg (about 70 to 130 MB each).
- Launch on older macOS (A-3.1.2-13): a hard link to newer symbols would stop the editor, the player and the recorder from starting on macOS 11 to 14.5; checked in step 10.
