# ai-notes: security model (owner: architect; index in ai-docs/architecture.md)

## Threats
malicious media names and contents; malicious project JSON and settings file; PATH hijack; tampered downloads (ffmpeg build, speech model); filtergraph / ASS / ffconcat injection; desktop entry injection; hostile GPU drivers (contained in a child process; a full system hang inside a driver cannot be prevented, documented).

## Core rules (all versions)
- No shell: every child process is started with an argument list (OsString args); file arguments use the `file:` prefix; `-protocol_whitelist file,pipe`; `-nostdin -hide_banner`; `-y` only on our own temp output.
- spawn cwd only our private work folder (0700, ADR-033).
- Bundled ffmpeg = a shipped untrusted-media parser: refresh pin every release; SHA-256 pinned at build; settings show path, version, source (bundled / override / PATH). PATH last. Override must be absolute and an existing regular file.
- Settings file: untrusted for parsing (malformed -> recommended), trusted at account level for the override (the writer can already run code as the user; stated in the threat model). Size cap 64 KiB; regular file only.
- Project file: strict serde, 16 MiB cap, regular file only (FIFO/device refused; bounded read via take(MAX+1)), full invariant validation, nesting limit 128 (test > 200 levels refused). Unknown newer formats refused and never written.
- Media paths from projects: read-only by ffprobe/ffmpeg; probe rejects non-regular; probe timeout 30 s -> "could not be analysed in time". Relative `..` resolved against project folder, still read-only (accepted, documented).
- Concat: any control character in a source path -> no stream copy, re-encode path (-i args safe). [0.3.0 fix of concat_quote bug]
- Display: control characters + bidi overrides (U+202A–202E, U+2066–2069) -> U+FFFD in displayed names only. Also used for track titles (<= 64 chars).
- Unsafe: crate-wide `#![deny(unsafe_code)]` in lib.rs (0.3.0); `#[allow(unsafe_code)]` only on stt::whisper (abort callback, reviewed) and desktop::macos (objc2 Apple Event handler). Nothing else. Unsafe is forbidden in the whole program except those two reviewed places.
- Downloads (REQ-058): URLs only from the ModelSpec table (test: all https://); fetch refuses non-https before any connection (offline testable); ureq https_only also for redirects, max 5 redirects, connect and read timeouts; HTTPS_PROXY honoured; size limit spec.size+1; sha-256 checked before rename; partial or wrong sha -> delete .part; ureq used only in stt::download (include_str! grep test). Consent before any network call (32 MB level or chosen level). No telemetry, no update check.
- Model files: user-supplied file must match size + sha-256 before whisper.cpp (C++ parser) loads it; before each load size check + sha once per session (memo by path, size, mtime).
- Proxy cache: hash names; clear deletes only the own pattern in our dir.
- Linux desktop integration writes only ~/.local/share (menu entry, icon, mime); Exec quoted per desktop-entry spec; target absolute existing file; helpers called with absolute args, no shell, errors ignored.
- macOS odoc paths -> the same open/validation path as a user pick.
- Supply chain (ADR-025, ADR-034): Cargo.lock committed, release builds --locked; cargo-deny in CI (licence allow-list: MIT, Apache-2.0, Apache-2.0 WITH LLVM-exception, BSD-2-Clause, BSD-3-Clause, ISC, Zlib, Unicode-3.0, Unlicense, CDLA-Permissive-2.0, BSL-1.0, MPL-2.0; advisories; yanked = deny; bans; ignore list empty; any ignore needs a written reason); cargo-about notices regenerated and diffed in CI; ffmpeg archives and appimagetool pinned by SHA-256 (packaging/ffmpeg.lock, packaging/tools.lock); optional weekly advisory check.
- CI (ADR-036, ADR-034): top-level permissions contents: read; contents: write only in the package job; third-party actions pinned by full commit SHA with tag comment; runners ubuntu-24.04, macos-15, windows-2025. Player CI check: no ureq / whisper-rs in its graph.
- Secrets: none. Telemetry: none. Network: only the speech model download (after consent); the player has none.
- Installers unsigned (decided by Andrea); Windows SmartScreen and macOS Gatekeeper warnings; macOS app sealed with an ad-hoc signature (`codesign --force --deep --sign -`); README explains first launch; signing postponed, not rejected.
- Corpus tests (REQ-057): bad/truncated JSON, nesting > 200, > 16 MiB, 1e309, u64::MAX, negative times, ../../etc/passwd, absolute paths to non-media, control and bidi in names, Unix FIFO project (return < 1 s), settings corpus (layout NaN/±inf/negative/>1/strings, recent 10k entries, relative paths, NUL, 5 KB paths, non-strings), SRT corpus (overflow times, 200k cues, binary junk, CRLF/BOM), NaN/huge numbers in new fields (ints -> serde rejects floats), 10k POVs, 1 MB titles. Every case: no crash, clear refusal, nothing written, sources unchanged.

- 1.2.6: sendcmd file and filter args built only from validated ints formatted by us; no user or file string reaches ffmpeg or ASS; metadata read = enumerated ffprobe values; POV count/values bounded on load (ADR-065); command file in private Work folder (0700), relative name, escaped; hostile 8K / huge dims -> too_large gate (u32 ints, u64 products, no overflow).
