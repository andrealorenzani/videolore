# ai-notes: security model (owner: architect; index in ai-docs/architecture.md)

Human version: docs/architecture-security.md. This file lists the rules the code must keep, with their origin.

## Threats
Malicious media names and contents; malicious project JSON and settings; PATH hijack; tampered downloads (ffmpeg build, speech model); filtergraph, ASS and ffconcat injection; desktop-entry injection; hostile GPU drivers (contained in a child process; a whole-system hang inside a driver cannot be prevented).

## Core rules (all versions)
- No shell: children start with an argument list (OsString). File arguments carry `file:`; `-protocol_whitelist file,pipe`; `-nostdin -hide_banner`; `-y` only on our own temporary output. Spawn cwd only the private work folder (0700, ADR-033).
- Bundled ffmpeg is a shipped untrusted-media parser: pin refreshed every release; SHA-256 at build; settings show path, version and source (bundled, override, PATH). PATH last. An override must be absolute and an existing regular file.
- Settings: untrusted for parsing (malformed → recommended); trusted at account level for the override (stated). 64 KiB cap; regular file only.
- Project: strict serde; 16 MiB cap (96 MiB from format 11, ADR-191); regular file only (FIFO and device refused; bounded read through `take(MAX+1)`); full invariant validation; nesting limit 128 (more than 200 levels refused in tests). Newer formats refused and never written.
- Media paths in projects: read-only for ffprobe and ffmpeg; the probe rejects non-regular files; probe timeout 30 s ("could not be analysed in time"). Relative `..` resolves against the project folder, read-only (accepted).
- Concat: a control character in a source path → no stream copy, re-encode path (0.3.0 fix).
- Display: control characters and bidi overrides (U+202A–202E, U+2066–2069) → U+FFFD in displayed names only; also track titles (≤ 64 characters).
- Unsafe: `#![deny(unsafe_code)]` in lib.rs (0.3.0); allowed only in `stt::whisper` (abort callback, reviewed) and `desktop::macos` (objc2 Apple Event handler, and since 2.0.4 the one menu-bar call, ADR-183 amending ADR-034).
- Downloads (REQ-058): URLs only from the `ModelSpec` table (test: all https://); non-https refused before any connection; ureq https-only including redirects; redirects ≤ 5; connect and read timeouts; `HTTPS_PROXY` honoured; size limit spec.size + 1; SHA-256 before rename; wrong or partial → delete `.part`; ureq only in `stt::download` (grep test). Consent before any network call. No telemetry, no update check.
- Model files: a user-supplied file must match size and SHA-256 before whisper.cpp loads it; size checked before each load and SHA-256 once per session (memo by path, size, mtime).
- Proxy cache: hashed names; clear deletes only its own pattern in its own folder.
- Linux desktop integration writes only `~/.local/share`; Exec quoted per the desktop-entry spec; target an absolute existing file; helpers with absolute arguments, no shell, errors ignored.
- macOS open-document paths use the same open and validation path as a user pick.
- Supply chain (ADR-025, ADR-034): `Cargo.lock` committed; `--locked` release builds; cargo-deny in CI (licence allow-list: MIT, Apache-2.0, Apache-2.0 WITH LLVM-exception, BSD-2-Clause, BSD-3-Clause, ISC, Zlib, Unicode-3.0, Unlicense, CDLA-Permissive-2.0, BSL-1.0, MPL-2.0; advisories; yanked = deny; bans; empty ignore list; any ignore needs a written reason); cargo-about notices regenerated and diffed in CI; ffmpeg archives and appimagetool pinned by SHA-256 (`packaging/ffmpeg.lock`, `packaging/tools.lock`); weekly advisory run (2.0.4, read-only).
- CI (ADR-036, ADR-034): top-level `contents: read`; `contents: write` only in the package job; third-party actions pinned by full SHA with a tag comment; runners ubuntu-24.04, macos-15, windows-2025. Player check: no `ureq` or `whisper-rs` in its graph.
- No secrets; no telemetry; network only for the speech download (after consent); the player has no network code.
- Installers unsigned (decided by Andrea): SmartScreen and Gatekeeper warnings; macOS app sealed ad hoc (`codesign --force --deep --sign -`); signing postponed, not rejected.
- Corpus tests (REQ-057): bad or truncated JSON; nesting > 200; > 16 MiB; 1e309; u64::MAX; negative times; `../../etc/passwd`; absolute paths to non-media; control and bidi in names; a FIFO as project (returns < 1 s); settings corpus (NaN, ±inf, negative, > 1, strings, 10k recent entries, relative paths, NUL, 5 KB paths, non-strings); SRT corpus (overflow, 200k cues, binary, CRLF, BOM); NaN and huge numbers in new fields (integers only: serde rejects floats there); 10k POVs; 1 MB titles. Each: no crash, clear refusal, nothing written, sources unchanged.

## By version (origin of each rule)
- 3.1.2 (built, ADR-260, 261, 264, 263): recorder args only numbers, closed lists, user folder and file name, screen geometry; protocols file, pipe, tcp; TCP listener 127.0.0.1, ephemeral, one connection per source, peer must be 127.0.0.1; PCM never stored; `-y` only after Replace; fragmented MP4; settings v1 corpus test (64 KiB, regular file); no network; unsafe: only `screen-spy/src/macos.rs` (AVFoundation microphone and CoreAudio tap, seven SAFETY sites; the screen check is safe); the recorder spawns ffmpeg only in `process.rs`; `-nostdin` exception for the recording child (stdin `q`).
- 3.1.0 (planned, ADR-245, 249, 244): audio track number checked 0..31 and written only as an integer into argv; ffprobe audio list capped at 32, titles ≤ 64 characters sanitised; every save writes format 15 (ADR-244), refused by older programs, which never write it; As-track text through the SRT writer.
- 0.2.0: ADR-025 supply chain; ADR-026 notices (ffmpeg version read at runtime); ADR-013 bundled ffmpeg (source as release asset); ADR-021 speech download consent, https, sha; ADR-024 quit path.
- 0.3.0 (ADR-033, ADR-034): settings corpus and FIFO refusal; probe timeout 30 s; concat control-character guard; display sanitising; `deny(unsafe_code)` with two allows; downloads https-only pre-connect check, redirect cap 5, model URL table test, ureq only in the downloader; private work folder 0700, partial exports 0600, lock-based crash cleanup restricted to own patterns, regular non-symlink files; cache and data dirs 0700; cargo-deny yanked = deny; CI least privilege and SHA-pinned actions.
- 0.4.0 (ADR-037 to 040): probe input synthetic lavfi (no file access); VA-API device string only from enumerated `^renderD\d+$` character devices, no shell; hardware output is untrusted media, decoded only by the software decoder; `hardware_off` fields validated (enum, ≤ 32 characters, ≤ 8 entries); no new crate, no network; GPU drivers are system components; driver crash or hang contained (kill, abandon); libva guard reads ffmpeg and libva.so.2 as bytes only (no dlopen or exec), bounded to known paths; prevents the bundled ffmpeg core dump on libva < 2.21.
- 1.1.0 (ADR-044, ADR-047): dropped paths get the same checks as File > Import (probe hardening) or File > Open (`.vlproj` via `project::load`, REQ-028 prompt); drops ignored while a modal is open. Recent list is untrusted: string, absolute, ≤ 1024 bytes, no control or NUL, max 10; displayed sanitised; opened only by an explicit click through the same load path; missing → message and removed; non-UTF-8 never stored. Layout values finite in (0, 1). Recent paths stored in the user's config directory; "Clear list" removes them.
- 1.2.0 (ADR-051, 053, 054, 057): embedded subtitle data is untrusted media content converted by ffmpeg to SRT in the private 0700 folder under a fixed name; `read_limited` 16 MiB; `srt::parse` total (checked arithmetic, 100k cues, `MAX_TEXT`, finite times); `strip_tags` and `clean_text` before use; ASS `escape()` still applied; `\pos` only from validated u16. ffprobe subtitle metadata: codec allow list; language regex `[A-Za-z0-9-]{1,16}`; title ≤ 64 characters; ≤ 16 tracks; ordinal u8 from our own count. Project v3: volume ≤ 100 and Pos ≤ 10000, else refused; unknown ids refused; `subtitle_tracks` sanitised (never refuses). SRT output: user path from the save dialog, `write_atomic`, no shell. "Use without matching words" works offline.
- 1.2.6: sendcmd file and filter arguments built only from validated integers formatted by us; no user or file string reaches ffmpeg or ASS; metadata read = enumerated ffprobe values; POV count and values bounded on load (ADR-065); command file in the private Work folder, relative name, escaped; hostile 8K or huge dimensions → too-large gate (u32 integers, u64 products, no overflow).
- 1.3.0: text and font names untrusted: ASS escape (ADR-020 path); font charset whitelist ≤ 100 characters; colour `#RRGGBB`; numbers formatted by us; caps 2000 and 20000 events; font files regular, ≤ 64 MiB, on a worker; system fonts parsed by OS, libass and FreeType (trusted, risk noted); anchors validated on load. 360 marker writer (ADR-078): only the moov box read (size-capped), the rest copied.
- 1.4.0 (ADR-082): export dialog text untrusted: name rules (no separators, control characters, reserved Windows names, ≤ 200 characters; extension from a table); folder must be an existing directory; `Path::join` of a validated name only; a target equal to any project media or the `.vlproj` refused; overwrite needs confirmation; partial in the target folder then rename. ffmpeg arguments from enums and constants; mp3 only when probed.
