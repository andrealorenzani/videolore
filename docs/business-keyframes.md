# Business — Whole-video and keyframe clarity (2.0.4)

Back to the [index](business.md). Batch 7 of the [roadmap tasks](roadmap_tasks.md), built in the 2.0.4 development. Decided by Andrea on 2026-11-20: the whole-video keyframe copies are shown apart, one per clip, and are not edited all together.
## Requirements
- REQ-200 (implemented): The whole-video Scale or Move popup (REQ-148) shows one row per clip with its own copy of the keyframes. Selecting a row shows that clip's keyframes on the timeline; keyframe changes, Add and Remove apply to the selected copy only. Remove effect still removes every copy, with one undo step. This replaces the 2.0.3 rule that a change in the whole-video popup changes all copies. Amends REQ-148. Acceptance: the popup of a whole-video Scale on three clips lists three rows; selecting clip 2 and changing its keyframe leaves clips 1 and 3 unchanged; Remove effect removes all three copies and one undo restores them.
- REQ-201 (implemented): When a clip is added (appended, pasted or split off) while a whole-video effect is on the timeline, the status bar reads "The new clip has no <effect>" with the button **Apply to new clips**. The button gives the clip the whole-video effect, as a double-click does (REQ-147), in one undo step. Without the button the clip gets nothing (REQ-147 stays). Acceptance: a whole-video Volume of 50% and an appended clip: the notice appears; the button sets the new clip to 50% and changes no other clip; one undo removes it; without the button the new clip has no Volume.
- REQ-202 (implemented): When a clip and the whole video both have Scale or Move, the preview shows both sets of picture handles: the clip's solid and the whole video's dashed. Dragging a handle changes only the effect it belongs to. Built reading: a clip has one Scale and one Move, so the dashed handles are the whole-video copy selected in the open whole-video popup when that copy belongs to another clip than the one under the playhead; a drag changes only the copy its handle belongs to (to be confirmed by Andrea). Amends REQ-127 and REQ-128 (known limitation of 1.5.0). Acceptance: a clip with Scale and a whole-video Scale shows two boxes; dragging the clip's corner changes the clip's Scale only; the whole video's value is unchanged.
- REQ-203 (implemented): In the Scale and Move keyframe timeline, a keyframe marker is at least 12 pixels across, and a click within 8 pixels of a keyframe selects it. The selected keyframe's time and value are shown in fields that accept typed values. When the popup has keyboard focus, Left and Right move the selected keyframe by one frame. Acceptance: a click 6 pixels from a keyframe selects it; a typed value changes it; with focus in the popup Right moves the keyframe by one frame; the usability check in real use is in [verification](business-verification.md).
- REQ-204 (implemented): A clip's Scale or Move popup has **Copy keyframes** and a **Paste keyframes to** list with the other clips. Pasting replaces the target clip's keyframes of that effect with the copied ones, in clip time, and does not change its other effects. One undo step per paste. Acceptance: copy the Scale keyframes of clip 1 and paste them to clip 3: clip 3 has the same keyframes at the same clip times; one undo restores clip 3.
- REQ-205 (implemented): A double-click that gives a clip the Apply LUT file it already has changes nothing: the status line reads "The clip already uses <file name>" and no undo step is added. A different file replaces the clip's LUT as before (REQ-135). Acceptance: double-click with the same file leaves the clip and the undo history unchanged and shows the message; with another file the LUT changes.

## Key decisions (2.0.4)
- Decided by Andrea on 2026-11-20 (2.0.2 record): the copies are shown apart; the whole-video popup no longer edits all of them at once (REQ-200).
- [MINOR] The notice of REQ-201 is an offer, never an automatic change, so REQ-147 keeps its meaning.
- [MINOR] A same-file double-click keeps the clip's current LUT; a LUT strength (REQ-289) would be kept with it.

## Impact on existing features
- REQ-148 changes as in REQ-200; its tests change with it.
- REQ-202 changes the handles drawn on the picture of a clip with its own and a whole-video effect.
