# Changelog

Changes since the last release, newest first. Each entry: version and date-time. On release the entries become `releases/<version> - <name>/RELEASE_NOTES.md` and this file is cleaned.

## 2.0.4 — 2026-11-21 00:15 +0000
- Added: subtitle files and fonts: File > Export subtitles… writes .srt, WebVTT (.vtt) and ASS (.ass, with each line's own place and size); the Full video export can keep subtitles as a separate track the player can switch off (burned into the picture stays the default); File > Import subtitles… reads .srt and .vtt files, with optional re-timing from the speech; a video with a .srt or .vtt file of the same name beside it is offered its subtitles; bundled fonts for Arabic and Devanagari (Chinese, Japanese and Korean use the fonts installed on the computer).
- Added: editing gestures, autosave and safety: a project with unsaved changes is autosaved every 2 minutes to a private cache folder, and a newer autosave is offered at the next start; drag a clip's edges to trim it (one frame at a time) and drag subtitle and fade markers; the keys [ and ] move between timeline markers; Ctrl/Cmd+V pastes the most recent cut or copy made in videolore; removing a media file keeps the other undo steps; several subtitle lines can be deleted together or shifted 0.5 s earlier or later; moved lines and texts snap to the picture's centre lines and thirds; View > Show safe areas.
- Added: whole-video and keyframe clarity: the whole-video Scale or Move popup shows one row per clip with its own keyframes; a note appears when a clip is added while a whole-video effect is on; both the clip's and the whole video's picture handles are shown; keyframe markers are easier to hit; Copy keyframes and Paste keyframes to other clips; applying the LUT a clip already has changes nothing.
- Changed: faster hardware export and hardware reach: the hardware check is cheaper and waits while an export or subtitle job runs; a candidate that runs out of time twice is skipped for the session; a busy computer is told apart from a hanging candidate, and Settings > Advanced shows "check inconclusive, repeating"; on integrated graphics Settings explains that Faster may not be quicker; AV1 (MP4) and VP9 (WebM) export presets when the encoder is found; hardware decoding for the preview with Faster when the codec is supported; Settings > Advanced lists the working video hardware, with Automatic as the choice; a message when the system video library is older than the bundled ffmpeg needs; Quick Sync uses constant quality when its driver refuses bitrate control.
- Changed: export and preview speed: the Export dialog's video entries use plain codec names; it warns when the longer side of the frame is above 4096 px; the blurred background is kept in the preview while its inputs do not change; importing, preview copies and subtitle preparation never delay playback or an export.
- Changed: platforms and installers: the installer check runs on pull requests that change packaging and a security-advisory check runs weekly; the Windows installer tools are pinned by version and checksum, and its licence page shows the non-ASCII text correctly; on Windows and Linux a double-clicked project opens in the running window; the Linux archive has a desktop entry and a launcher; on macOS the menu bar is at the top of the screen with Hide, Hide Others and Minimize (Cmd+Q still asks about unsaved changes); dropped files are read where the windowing library reports them.
- Changed: interface: window size and position, popup positions, and the layout of the sections are remembered; sections can be hidden, collapsed to their header or docked on the other side of the Preview; View > Workspaces saves and switches layouts; the toolbar can be customised and shows icons only or icons with text; Help > Keyboard shortcuts lets you change a binding; View > Theme offers System, Light and Dark; a text size choice in Settings; buttons, menus, sections and popups have names for screen readers; the Edit menu is grouped in submenus; the interface is in English only.
- Added: video player: the installers add the player to "Open with" for MP4, MOV, MKV, WebM, M4V and AVI files (it becomes the default only if you choose it); File > Open in player (editor) and File > Open in editor (player) move a file between the two programs; File > Add to playlist and File > Open folder… build a playlist; the player remembers its volume, mute, the last folder and full-screen start; subtitle positions are kept while the same file stays open; very large videos keep their sound; the About screen lists the player's own components.
- Added: 360 video: a clip can be marked as a 360° video in Clip details; a 360 export to Matroska or WebM carries the 360 information that players read, as MP4 and MOV do; a 360 export keeps the spherical information of its source; with the 360 choice the presets are greyed out with the reason, and a note says that frame effects are not applied; 360 export always uses the speed-first settings; the view is drawn at half size while the camera is dragged; a file's starting view is used; the camera can roll (Shift+drag), points of view can ease in and out, and the arrow keys, Page Up and Page Down steer the camera when the preview has focus.
- Added: effects and frame: the length of each fade is chosen (0.1 s to half the shorter clip); fades can be out only, in only or both; a music clip has its own volume and fades; Clean audio can be applied to a music clip and to the music track, with a Strength slider and an Enhance speech switch (level normalisation after noise reduction, no speech model); volume keyframes on the Scale and Move timeline; keyframe segments ease in and out; Crop for one video clip; Change aspect has a Blur choice (Low, Medium, High) and a Custom aspect; Apply LUT has a Strength slider, reads .3dl and .csp files as well as .cube, scales input ranges other than 0 to 1, asks to find a missing LUT file before export, keeps a copy of each LUT in the project, and keeps a list of up to 20 favourite LUTs.
- Added: continuous quality: Settings > Show the start screen offers "At every start" (the default), "Once for each version" and "Never"; after Clear preview copies the copies of the open project are made again at once in the background; the preview copy cache has a 4 GB size limit in Settings, and the oldest copies are removed first; the project page has a social preview image and a Content-Security-Policy.
- Changed: project format 11, one bump for this version: projects saved by 2.0.4 use the new format; projects of format 10 open unchanged; 2.0.3 and older refuse format 11 with a message and leave the file untouched.
- Workflow: manual checks for 2.0.4 added to the [release verification](business-verification.md) (not a blocker for the release).
