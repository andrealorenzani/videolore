# Changelog

Changes since the last release, newest first. Each entry: version and date-time. On release the entries become `releases/<version> - <name>/RELEASE_NOTES.md` and this file is cleaned.

## 2.0.2 — 2026-11-20 20:34 +0000
- Changed: business plan for 2.0.2 (see [business](business.md) and [release verification](business-verification.md)): REQ-154 (implemented) the splash summary fits its popup, from 15 px down to 7 px, and is never scrolled; quality goals QG-07 to QG-10 (bundled ffmpeg checks, pinned ffmpeg for the tests, tests independent of the machine load, checks in the automatic builds); a manual release checklist for the maintainer; Andrea's decisions: installers stay unsigned (code signing and notarisation not planned), the Export dialog keeps its presets (custom values not planned), hardware export always goes through ffmpeg, AV1 and VP9 encoding and hardware decoding are in scope (not built yet), whole-video keyframe copies are shown apart in the popup (not built yet), the 360 export prioritises speed. The roadmap batches are renumbered: batch N ships as 2.0.(N+1); 2.0.1 (module-cycles refactor) is delivered.
- Changed: architecture for 2.0.2 (see [release verification](architecture-verification.md)): the Linux check job runs the ffmpeg 9.0.2 build pinned in `packaging/ffmpeg.lock` (SHA-256 checked, cached, missing ffmpeg fails the job) instead of the runner's package, and the tests fail on another version; the splash summaries shrink from 15 px to a 7 px floor and never scroll (REQ-154); time-based product gates pass on the best of up to five samples with the limits unchanged, and hardware probe limits are injected; the notices check exit codes, the pinned cargo-about 0.9.3 and the Windows (NSIS), macOS (app) and Linux (AppImage) installer configurations are checked on every push; there is no `.deb` package; the 360 camera timing is measured again on the 9.0.2 build.
- Added: code for 2.0.2 (see [code](code.md)): tests for REQ-121, REQ-137, REQ-144 and REQ-154 (feature coverage 153/153, line coverage 95.6%); the `best_of` test helper in `src/base/testing.rs` (time-based checks take the best of up to five samples, limits unchanged); a `package-config` CI job and `scripts/package.sh <target> --stub` for the AppImage from stub binaries. Changed: the CI test job runs on the pinned bundled ffmpeg 9.0.2, the notices check records its exit code and cargo-about 0.9.3 is installed by a fixed method; the four UI frame tests still use fixed limits (roadmap). The CI changes are not yet verified on a real runner.

## 2.0.1 — 2026-11-20 20:06 +0000
- Changed: business requirements for the code structure (REQ-151..153, delivered): the shared helpers move to one common module, with no change in behaviour, no module cycle and an automatic check that fails when a cycle is added.
- Changed: architecture for 2.0.1 (see [code structure](architecture-structure.md)): a new `base` module in `src/base/` for the shared helpers (file reading and writing, private work folders, positions, names, language table); the module cycles are broken; the automatic cycle check runs in `cargo test`; `syn` is a development dependency (already in the lock file, no new package).

No file format, setting, file name or output changes.
