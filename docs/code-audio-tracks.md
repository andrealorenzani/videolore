# Code — 3.1.0: audio tracks, Enlarge word from its base, As subtitle track, project format 15

Back to the [index](code.md). REQ-334 to REQ-340. Symbols and tests: [code-index.md](code-index.md) or `scripts/req-code.sh REQ-NNN`.

## Audio tracks (REQ-340, 339, 338)
- **Model.** `media::AudioTrack { ordinal, language, title, channels }` (the ordinal counts the audio streams only: `-map 0:a:<ordinal>`; at most `MAX_AUDIO_TRACKS` = 32; titles and languages sanitised like subtitle tracks; `label()` = language or title plus "(mono)", "(stereo)" or "(N channels)"). `MediaFormat.audio_tracks: Option<Vec<AudioTrack>>`: `None` = not analysed (media of earlier versions; the check that finds subtitle tracks, `app/subs_create.rs:start_track_check`, also fills it, through `ProjectDoc::set_audio_tracks`, so the project does not become unsaved), `Some(empty)` = no sound. `Clip.audio_track: u8` (not written when 0; split and the template of an insert copy it; Merge compares it: `timeline::DIFFERENT_AUDIO_TRACKS`).
- **Load rules** (`project.rs`): tracks of a media entry sanitised and cut to 32; `validate_audio_tracks` sets a clip's track back to 0 when the file has fewer tracks (or was never analysed and the track is above 0) and adds one status line "N clip track choices reset"; a number that is not a byte is a damaged file (refused).
- **Command.** `Command::SetClipAudioTrack { clip, track }` (undo name "Audio track"; `AppState::set_clip_audio_track` refuses a track the file does not have, nothing happens for the same track), `AppState::audio_track_labels(media)` (the list the popups show: a file not analysed shows "Track 1", a file without sound none).
- **Popups.** `ui/effects.rs:audio_track_choice` in the clip's Volume popup; `subtitle_audio_choice` in the Subtitles popup (state `Popups.subtitle_audio`, set by `Command::SetSubtitleAudio(u8)`: not an edit, not stored; `create_subtitles` copies it into `CreateRequest.audio`, `continue_create` into `RangeJob.audio`, falling back to 0 when the file has fewer tracks). The Volume effect is named "Volume and track" (`SPECS`, `ActionId` labels, `Popup::title`, the Applied effects row; the undo name stays "Volume").
- **Render.** `Segment.audio_track`; `render/graph.rs` makes one audio stream per input and track (`fan_out(.., kind, track, users)`: `[n:a:k]`, the split labels carry `t<k>` for k ≠ 0, so the labels and the argv of track 0 are the ones of 3.0.x); a clip with track ≠ 0 is not "no effects": no stream copy (`plan_export_choice`). `SpatialJob.track` (`-map 0:a:<track>`, part of the file name hash; `is_ambisonic_track` judges the track's own channel count). `stt::extraction_args(.., track)` (`-map 0:a:<track>`). Proxies keep every audio stream (`-map 0:a?`, `PARAMS_VERSION` 3: old proxies are rebuilt once). `FrameKey.audio_track`.
- **Player.** `Command::ChooseAudio(u8)`; `PlayerState::audio_tracks`, `audio_track`; the clip of the one-clip project gets `set_audio_track`; `audio_memory` (by canonical path, session only) re-applies the choice when the same file is opened again; `ui.rs:audio_menu`. Nothing is saved (REQ-252).

## Enlarge word from its base (REQ-334)
- `src/word_layout.rs` (pure): `Block { slots, line_widths, centre, px, descent }`, `Block::with_enlarged(i, big_px)` gives each word's left edge, the bottom of its line box and its size: the enlarged word keeps its baseline (`bottom += descent * (big - px)`), its left moves by half the extra width (its centre stays), words before it on its line move left and after it right by the same half, other lines do not move. `measure::Shaped::descent()` (the OS/2 `usWinDescent` over the line height, the `hhea` descender as fallback).
- `ass.rs:word_block` measures the line (the old `word_centres` is gone) and `document_styled` writes, for each spoken word, one event per word: `word_styles::enlarge_placed` → `{\an1\pos(x,y)[\bord..]\fs<size>}text`; when the text cannot be measured, `word_styles::enlarge` (in-line form, as 2.1.0). REQ-333's placement rule is replaced (its measuring test, `measure::words_are_placed...`, still carries `// covers: REQ-333`). Projects with Enlarge word look different when opened (release note).

## As subtitle track (REQ-337)
- `Preset::AsTrack` (`as_track`, "As subtitle track"; the preview uses the Classic look: `ass.rs` arms). `plan_export_choice`: `as_track` forces the separate track whatever the Export dialog says and never burns the lines (`burn = track.is_none() && !as_track`); texts stay burned. `export::choice::Context.subtitles_as_track`, `subtitle_mode`, `AS_TRACK_REASON`: the dialog's Subtitles choice is disabled and says why. A 360 export uses the same writer.

## Blurred fill (REQ-335)
- Cause (A-3.1-3 was a guess; this is measured): the preview keeps the blurred background of a still (`FrameKey::background_name`, REQ-223) and reads it back as the background of the picture; for a clip's own Change aspect the frame is smaller than the output, so the kept picture had the wrong size and place and the fill disappeared (the export was right). `FrameKey.own_aspect` turns the kept background off for it. Test: `v31::the_preview_of_a_clips_own_blurred_aspect_matches_the_whole_render_and_has_the_fill` (failed with a mean difference of 44 before the change).

## Overlap media row (REQ-336)
- `ui/effects.rs:new_object_row` draws "Add Text" and "Overlap media" as two rows of the effect width (`Button::selectable`, min width = the section width); the Effects section now has 11 rows, so the last one scrolls at 800 px: tests that drag from the lower rows use a 1000 px window (`lut_ux_tests`).

## Project format 15 (REQ-029, 340, 337)
- `SCHEMA_VERSION` 15, written on every save (ADR-244); 1 to 15 open, 16 or more is `TooNew` (file untouched). New fields (`audio_track`, `audio_tracks`, `as_track`) are written only when used, so a project that uses none of them is the same as a 3.0.x file apart from its number. 3.0.x refuses every file saved by 3.1.0 (release note). Tests: `project/v15_tests.rs`.
